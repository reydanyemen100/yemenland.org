# YHDF Website

Static bilingual Arabic/English website for Yemenland for Humanitarian Development Foundation.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `yemenland.org`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/root`, then Save.
5. GitHub will provide a temporary Pages URL.
6. In Namecheap DNS, keep the Zoho/Google MX records unchanged. Add GitHub Pages records according to the current GitHub Pages instructions, then add the custom domain in GitHub Pages.

The site is designed as a static website, so no paid hosting is required. Replace the placeholder contact details and generic program copy with the approved text from the institutional profile before publishing.
